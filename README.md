# Drone_00
Hardware 
1) 4 BLDC motor
2) 4 ESC / 4 in 1 ESC PCB
3) Flight controller
4) Barometer for altitude detection
5) GPS for location tracking
6) Remote control to send command
7) Digital video camera

# Software
First option is using STM8 microcontroller for less price
1)SDCC for compilation
2)stm8flash for flash hex file to STM8 microcontroller

Second option is using STm32 microcontroller for high price
1)STM32 cube

# Requirements
Drone to be controlled wirelessly for yaw, pitch, roll.
Need to have return to home functionality in case of loss of communication

# Wishlist
Need flight time of drone to be more than 1 hour
